# 写小白能懂的财经文章

## 核心原则

读者是财经小白：看得懂新闻标题，看不懂正文。财经写作有三个独有的陷阱，本文的全部规则都为了绕开它们：

1. **术语是行话**--作者以为在解释，其实在翻译成另一句行话（药方见"嚼碎"一节）；
2. **机制看不见**--不像代码能跑，金融机制只能靠算账和类比让它现形；
3. **数字是信誉**--一个编造的精确数字比一段平庸的文字伤害大得多。

基线（无 skill）的写作已经有钩子、有小例子、有总结段；不要在这些上面花额外功夫。**差距永远在这五件事：嚼碎、算账、类比边界、真实锚点、事实纪律。**

## 嚼碎（第一道工序，写完通篇自检）

主概念一般都会解释，真正漏出去的是**次级术语**和**中间因果环节**。两条合同：

**1. 术语首现即白话。** 每个专业词第一次出现的那一句里，就要给白话定义或例子，句式：`术语（白话解释）`。

- ✅ "隔夜回购利率（银行之间借一夜钱用的利率）一度飙到 10%"
- ✅ "外汇储备（央行攒下的美元家底，可以卖掉换回本币、托住汇率）"
- 自检：从头扫一遍全文，凡是需要金融背景才能懂的词，首现处没有括号解释或例子的，补上。定义里不许再冒出没解释过的行话。

**2. 因果链一环一环走。** 任何"因为 A 所以 C"，中间的 B 必须写出来。"承压、利空、利好、流动性收紧、贬值压力"这类压缩词是行话重灾区，它们把一整条链压成了两个字：

- ❌ "美元走强，新兴市场承压"
- ✅ "美元走强 -> 资金把本币换成美元去赚高利息 -> 卖本币的人多了 -> 本币跌"
- 自检：把文中每个箭头、每个"因此"抽出来，问"读者能不能自己补出被跳过的那一环"，补不出来就展开写。
- 压缩词（承压、利空、贬值压力这类）在文中出现的位置，附近必须能找到它压缩的那条链至少完整展开过一次；只压缩不展开的地方，要么补链，要么删掉这个词换成链本身。

**另一篇文章讲过的知识不算读者已知**：本篇用到的每个机制，本篇自己嚼一遍（可以一笔带过地算，但不能只断言结论）。

## 文章骨架（正面模板）

### 1. 钩子：从新闻标题或切身困惑开始

- 读者在新闻里天天见但看不懂的词（"收益率倒挂"）、或身边的真实困惑（"为什么我的基金绿了"）
- ❌ 不以"X 是金融中的一个重要指标"开头

### 2. 一笔算得清的账（本文的核心差异点）

每个关键概念、每个公式，出现时必须立刻用**具体数字算一遍**：

- 公式之前先有算例：先讲"奶茶店卖 100 万、年赚 10 万"，再给 `市值÷净利润` 这个公式，顺序不可颠倒
- 每篇至少一笔**算到读者钱包的账**：不是"月供会上涨"，而是"100 万房贷、利率从 4.2% 到 4.7%，月供多出约 300 元"
- 算例数字要能自洽：读者拿计算器按一遍，得数要和你写的一致

### 3. 类比 + 失效边界

- 生活类比优先（借条、奶茶店、租金、团购）
- **每个类比必须交代一句"哪里失效"**：类比是脚手架，拆掉后读者该留下机制本身。例："把债券想成借条很管用，但借条不会天天有人报价，债券会"
- 读者懂技术 ≠ 要用程序员类比。只有当映射逐项成立时才用（如"分布式系统里的共识"对比"央行清算"），映射只成立一半就删掉
- ❌ 检验标准：把类比里的每个要素列出来，指不出对应的真实机制要素的类比，就是凑数类比

### 4. 反直觉时刻

财经概念的核心几乎总藏在一个"你以为 X，其实 Y"里（收益率涨 = 价格跌；P/E 低 ≠ 便宜；加息 ≠ 银行多赚钱）。找到它，放在显眼位置，用它制造章节间的台阶。

### 5. 真实世界锚点（基线最容易缺的东西）

每篇至少一处**真实发生过的事**或**真实可查的数字**托底：

- 真实历史事件（2022 年美联储 0→5.25% 的加息周期、硅谷银行 48 小时倒闭）
- 真实公司/资产的数据（某指数某年的实际市盈率区间）
- 全文只有假设例子 = 文章没有肌肉，只有骨架

### 6. 跟你有关 + 自测收尾

- 收尾落到读者可做的观察/动作："下次新闻里看到 X，你可以去看 Y，如果 Z 就说明……"
- 留 1-2 个自测问题（能答出 = 真懂了，答案指向文中某节）
- ❌ "跟你有关"一节禁止纯 bullet 清单腔：每一条都要么带数字，要么带具体场景，否则删

## 事实纪律（财经特有，违反即信誉事故）

- **每个具体数字，要么可查证，要么明确标注"大约/量级"**。宁可写"约 5 倍上下"，不写精确到小数点的编造数。对拿不准的数字，先联网核实再写
- **"历史上每次都……"级别的强因果断言必须带例外或不确定性**：倒挂预测衰退"几乎每次，但领先几个月到两年不等"才是一句负责任的话；裸的"每次都"不是
- 区分事实与观点：市场为什么涨，写"市场普遍解读为"，不写"因为"
- 个人博客不需要合规声明，但**不要给出具体买卖建议**，把读者送到"能自己看懂"为止

## 常见错误

| 错误 | 症状 | 修正 |
|---|---|---|
| 行话翻译行话 | 用"流动性""折现"解释"利率" | 回到第 2 步：先算一笔数字的账 |
| 次级术语裸用 | 主概念解释了，但"隔夜回购利率""结汇""止损单"首现无解释 | 首现即白话：`术语（白话解释）` |
| 压缩词掩埋链条 | "承压""贬值压力"一笔带过，中间环节全跳 | 一环一环展开：谁做了什么 -> 谁因此多了/少了什么 |
| 公式甩脸 | `(1+r)^n` 出现但全文没人算过一遍 | 公式永远在算例之后 |
| 凑数类比 | "读者懂技术"就硬塞进程/运行时类比 | 按第 3 步的映射检验，删 |
| 假设世界 | 全文没有一个真实事件/真实数字 | 补第 5 步锚点 |
| 清单腔结尾 | "跟你有关"三条 bullet 无数字无场景 | 每条带数字或场景，否则删 |
| 编造精确数字 | "该行不良率 1.73%"（查无此数） | 标"大约"或去核实 |

## 与 write-tech-docs 的关系

技术文章讲"机制可运行"，财经文章讲"利害可计算"。结构上两者共用钩子-分层-总结的骨架；本文只写财经独有的五件事：**嚼碎、算账、类比边界、真实锚点、事实纪律**。
